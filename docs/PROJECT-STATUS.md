Beim vollständigen `pnpm test:e2e`-Lauf (alle 3 Browser-Projekte, 462 Tests insgesamt — zuvor dokumentierte "154/154"-Zahlen aus früheren Sessionabschnitten waren jeweils nur ein Einzel-Browser-Lauf, nicht die volle Suite) fielen 89 von 462 Tests durch, **alle ausschließlich in Firefox**. (Missing 'unsafe-eval')` auf praktisch jeder Route, inklusive `/about` und anderer Seiten ohne jeden fachlichen Bezug zur eigentlichen Ursache. Mit einem Playwright-Diagnoseskript (`securitypolicyviolation`-Event mit Datei/Zeile/Spalte) den genauen Code lokalisiert: **`vuedraggable@4.1.0`** (genutzt für die Favoriten-Sortierung auf der Startseite, `src/pages/Home.page.vue`) liefert als `main`/`module`-Einstiegspunkt eine vorgebündelte, alte Webpack+core-js@2-Build-Artefaktdatei aus; deren Globalobjekt-Erkennung fällt auf `Function("return this")()` zurück, was die eigene CSP des Projekts (`script-src 'self'`, kein `unsafe-eval`) blockiert.
